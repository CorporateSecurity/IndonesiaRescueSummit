# Dashboard Peserta Indonesia Rescue Summit 2026

Dashboard React + Vite untuk menampilkan data peserta dan jumlah tim pada 7 cabang lomba.

## Menjalankan lokal
```bash
npm install
npm run dev
```

## Build production
```bash
npm run build
```

## Deploy
Repository ini siap di-upload ke GitHub lalu di-import ke Vercel.
- Framework: Vite
- Build command: `npm run build`
- Output directory: `dist`
